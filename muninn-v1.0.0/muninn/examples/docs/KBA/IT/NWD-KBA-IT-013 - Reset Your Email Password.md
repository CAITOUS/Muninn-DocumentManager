# Reset Your Email Password

## 1. OVERVIEW — Summary

### Summary

How to reset your Microsoft 365 email password yourself.

### Applies To

### Audience

All staff

## 2. BEFORE — Before You Begin

- Your work phone for the verification code

## 3. STEPS — Instructions

### Steps

1. **Go to the password reset page**
   Open aka.ms/sspr in a browser.
2. **Verify with your phone**
   Enter the code sent by text.
   > ⚠ Caution: Never share this code with anyone, including IT.
3. **Choose a new password**
   At least 14 characters; a short sentence works well.

### Expected Result

You can sign in to Outlook with the new password.

### Tips

- Update the password on your phone’s mail app too.
