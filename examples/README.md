# Examples

`docs/` is a small sample library for a fictional clinic, Northwind Dental Group. It holds one SOP with a screenshot and two KBAs, in exactly the format Muninn writes.

You can use it three ways:

- **Read it:** open the `.md` files on GitHub or in any editor to see the format.
- **Try local mode:** copy `docs/` to your computer, open `Muninn.html`, choose **Connect → Choose folder…**, and pick the copied folder.
- **Try repo mode:** fork this repository, then in Muninn choose **Connect → GitHub repo**, enter your fork, and set the docs folder to `examples/docs`. The `.switchboard-docs.json` file already marks it as a Muninn library.

You can also open `docs/` as an Obsidian vault.
